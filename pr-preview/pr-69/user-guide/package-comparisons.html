Package Comparisons

Compare Aalen-Johansen estimates across polarstate, lifelines, and tidycmprsk.

This page runs the same competing-risks example at the same five horizons in three implementations. The estimates agree after rounding; what differs is the API and the shape of the returned result.

Shared example

Each row is one observation. Code 0 means right-censored, 1 is the event of interest, and 2 is the competing event.

times 24.1 9.7 49.9 18.6 34.8 14.2 39.2 46.0 31.5 4.3
reals 1 1 1 1 0 2 1 2 0 1
  • polarstate (Python)
  • lifelines (Python)
  • tidycmprsk (R)

polarstate prepares one inspectable event table, then returns all state probabilities together.

import polars as pl
from polarstate import prepare_event_table, predict_aj_estimates

data = pl.DataFrame({
    "times": [24.1, 9.7, 49.9, 18.6, 34.8, 14.2, 39.2, 46.0, 31.5, 4.3],
    "reals": [1, 1, 1, 1, 0, 2, 1, 2, 0, 1],
})

event_table = prepare_event_table(data)

predict_aj_estimates(
    event_table,
    pl.Series([10.0, 20.0, 30.0, 40.0, 50.0]),
).select(
    pl.col("times"),
    pl.col("state_occupancy_probability_0").alias("event_free"),
    pl.col("state_occupancy_probability_1").alias("primary_event"),
    pl.col("state_occupancy_probability_2").alias("competing_event"),
)

lifelines fits one AalenJohansenFitter per event type. Combining the two predictions makes the comparison explicit.

import pandas as pd
from lifelines import AalenJohansenFitter

data = pd.DataFrame({
    "times": [24.1, 9.7, 49.9, 18.6, 34.8, 14.2, 39.2, 46.0, 31.5, 4.3],
    "reals": [1, 1, 1, 1, 0, 2, 1, 2, 0, 1],
})
horizons = [10.0, 20.0, 30.0, 40.0, 50.0]

primary = AalenJohansenFitter(calculate_variance=False)
primary.fit(data["times"], data["reals"], event_of_interest=1)

competing = AalenJohansenFitter(calculate_variance=False)
competing.fit(data["times"], data["reals"], event_of_interest=2)

comparison = pd.DataFrame({
    "time": horizons,
    "primary_event": primary.predict(horizons).to_numpy(),
    "competing_event": competing.predict(horizons).to_numpy(),
})
comparison

tidycmprsk returns outcome-specific estimates in a tidy table. The final pivot only places the two outcomes side by side.

library(dplyr)
library(tidyr)
library(tidycmprsk)

data <- tibble(
  times = c(24.1, 9.7, 49.9, 18.6, 34.8, 14.2, 39.2, 46.0, 31.5, 4.3),
  reals = factor(
    c(1, 1, 1, 1, 0, 2, 1, 2, 0, 1),
    levels = c(0, 1, 2),
    labels = c("censored", "primary_event", "competing_event")
  )
)
horizons <- c(10, 20, 30, 40, 50)

fit <- cuminc(Surv(times, reals) ~ 1, data)

tidy(fit, time = horizons) |>
  select(outcome, time, estimate) |>
  pivot_wider(names_from = outcome, values_from = estimate)

Rounded output:

time primary event competing event
10 0.200000 0.000000
20 0.300000 0.100000
30 0.400000 0.100000
40 0.566667 0.100000
50 0.733333 0.266667

See the official cuminc() documentation and tidying methods for the complete R API.

What differs?

Package Typical result Practical distinction
polarstate One Polars table with all three state probabilities Separates event-table preparation from horizon lookup
lifelines One pandas result per event of interest Fits an Aalen-Johansen object separately for each event type
tidycmprsk Outcome-specific rows in a tidy R table Uses an R formula interface and factor-coded outcomes

For data with no competing event, use only codes 0 and 1 in polarstate; the competing-event probability remains zero. See Recipes for that shorter pattern.
